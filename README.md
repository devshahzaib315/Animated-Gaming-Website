# GAMELAND — Animated Gaming Website

A responsive animated gaming landing page built with HTML, CSS, JavaScript, GSAP, and bundled media assets.

## Included sections

- Hero section with animated background videos and a working next-video preview control
- About section with an overview and an Explore button
- Featured worlds section with Nexus and Vault navigation targets
- Story section
- Contact section with email, GitHub, Instagram, and Telegram links

## Run locally

Open `index.html` in a browser, or use a local development server such as VS Code Live Server.

## Deploy to GitHub Pages or Vercel

Upload the contents of this folder to the repository root. For a static deployment, use the project root as the deployment root and leave the build command empty.
